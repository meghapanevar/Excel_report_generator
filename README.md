# Excel Report Generator

## Description
A Python-based application that reads sales data from a CSV file
and automatically generates a formatted Excel sales report.

## Technologies Used
- Python
- Pandas
- OpenPyXL
- Matplotlib
- Tkinter

## Features
- CSV file upload
- Total sales calculation
- Category-wise sales analysis
- Excel report generation
- Sales chart
- Summary dashboard
- Excel formatting

## How to Run

python gui.py# Excel Report Generator
